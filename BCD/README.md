🗄️ BCD — Banco de Dados
📖 Sobre a disciplina

A disciplina de BCD (Banco de Dados) apresenta conceitos fundamentais para armazenamento, organização, consulta e gerenciamento de informações.

Durante as aulas, são realizados exercícios e atividades práticas envolvendo bancos de dados, tabelas, relacionamentos e comandos SQL.

🎯 Objetivos
Compreender os conceitos fundamentais de banco de dados.
Conhecer a estrutura de bancos de dados relacionais.
Criar e organizar tabelas.
Trabalhar com relacionamentos entre tabelas.
Aprender comandos SQL.
Realizar consultas e manipulação de dados.
Desenvolver bancos de dados para aplicações.
🛠️ Tecnologias e ferramentas
SQL
MySQL
MySQL Workbench
Visual Studio Code
Git e GitHub
📝 Atividades

Os arquivos armazenados nesta pasta contêm exemplos de comandos SQL, criação de tabelas, consultas, inserção e alteração de dados, além de outras atividades realizadas durante o curso.

🚀 Objetivo da pasta

Organizar os conteúdos e exercícios desenvolvidos na disciplina de Banco de Dados, permitindo acompanhar minha evolução no aprendizado de SQL e na criação de estruturas de banco de dados.

🚀 PSOF — Projetos
📖 Sobre a disciplina

A disciplina de PSOF (Projetos) tem como objetivo aplicar, na prática, os conhecimentos adquiridos durante o curso de Desenvolvimento de Sistemas.

Nesta pasta estão reunidos projetos e trabalhos que envolvem diferentes áreas do desenvolvimento de sistemas, permitindo colocar em prática conceitos de frontend, backend, banco de dados e outras tecnologias.

🎯 Objetivos
Aplicar os conhecimentos adquiridos durante o curso.
Desenvolver projetos completos.
Trabalhar com organização e planejamento.
Integrar diferentes tecnologias.
Praticar programação e resolução de problemas.
Desenvolver sistemas funcionais.
Criar projetos para compor um portfólio.
🛠️ Tecnologias

As tecnologias utilizadas podem variar de acordo com cada projeto.

Entre elas podem estar:

HTML5
CSS3
JavaScript
SQL
Banco de Dados
Tecnologias de Backend
Git e GitHub
Visual Studio Code
📝 Projetos

Esta pasta será utilizada para armazenar os projetos desenvolvidos durante o curso, desde atividades menores até projetos mais completos.

Cada projeto poderá possuir seu próprio README com informações sobre:

Descrição do projeto;
Objetivo;
Tecnologias utilizadas;
Funcionalidades;
Como executar;
Imagens ou demonstrações.
🚀 Objetivo da pasta

Centralizar os projetos desenvolvidos durante o curso de Desenvolvimento de Sistemas e acompanhar minha evolução como desenvolvedor.

A pasta também poderá ser utilizada como base para a construção de um futuro portfólio profissional.

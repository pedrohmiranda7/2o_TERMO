## 💡 2. Módulo I: Planejamento de Projetos

### 1.1 Levantamento de Requisitos

- 🔎 Identificação do problema.
- 🎯 Definição dos objetivos.
- 👤 Levantamento das necessidades do usuário.
- ⚙️ Requisitos funcionais.
- 🛡️ Requisitos não funcionais.

### 1.2 Planejamento

- 📋 Definição do escopo.
- 📝 Organização das tarefas.
- 📅 Cronograma.
- 👥 Divisão de responsabilidades.
- 💻 Definição das tecnologias.

### 1.3 Documentação

- 📄 Descrição do projeto.
- 📝 Requisitos.
- 📐 Diagramas.
- 🗄️ Modelagem.
- 📚 Documentação técnica.

## 🎨 3. Módulo II: Desenvolvimento

### 2.1 Frontend

Aplicação dos conhecimentos de desenvolvimento de interfaces:

- 🌐 HTML.
- 🎨 CSS.
- 💻 JavaScript.
- 📱 Responsividade.
- 👤 Experiência do usuário.

### 2.2 Backend

Desenvolvimento da lógica da aplicação:

- 💻 Programação.
- 🔌 APIs.
- 🛣️ Rotas.
- 🔄 CRUD.
- ⚙️ Regras de negócio.

### 2.3 Banco de Dados

Utilização de bancos de dados para armazenamento das informações:

- 📐 Modelagem.
- 📊 Tabelas.
- 🔗 Relacionamentos.
- 🗄️ SQL.
- 🔎 Consultas.

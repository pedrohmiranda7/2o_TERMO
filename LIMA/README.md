📚 LIMA — Linguagem de Marcação
📖 Sobre a disciplina

A disciplina de LIMA (Linguagem de Marcação) tem como objetivo apresentar os principais conceitos relacionados à criação e estruturação de páginas e documentos utilizando linguagens de marcação.

Durante as aulas, são desenvolvidas atividades práticas para compreender como uma página web é estruturada e apresentada ao usuário.

🎯 Objetivos
Compreender os conceitos básicos de linguagens de marcação.
Aprender a estruturar páginas web.
Utilizar HTML para criação de páginas.
Utilizar CSS para estilização e apresentação.
Desenvolver páginas organizadas e responsivas.
Praticar a criação de interfaces para aplicações web.
🛠️ Tecnologias utilizadas
HTML5
CSS3
Visual Studio Code
Git e GitHub

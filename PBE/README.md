⚙️ PBE — Backend
📖 Sobre a disciplina

A disciplina de PBE (Programação Backend) é voltada para o desenvolvimento da parte responsável pelo processamento e funcionamento interno das aplicações.

Nesta pasta estão reunidos exercícios e projetos relacionados à programação, lógica, criação de funcionalidades e desenvolvimento de aplicações no lado do servidor.

🎯 Objetivos
Desenvolver conhecimentos de programação.
Aprimorar a lógica de programação.
Compreender o funcionamento do backend.
Trabalhar com dados e regras de negócio.
Desenvolver funcionalidades para aplicações.
Criar operações de cadastro, consulta, alteração e exclusão de dados.
Integrar aplicações com bancos de dados.
🛠️ Tecnologias e ferramentas
Linguagens de programação utilizadas durante o curso
APIs
Banco de Dados
Visual Studio Code
Git e GitHub
📝 Atividades

Os arquivos desta pasta representam as práticas realizadas durante as aulas, incluindo exercícios de programação, desenvolvimento de funcionalidades e projetos backend.

🚀 Objetivo da pasta

Organizar os conteúdos desenvolvidos durante o aprendizado de backend e acompanhar minha evolução na programação e no desenvolvimento de sistemas.
